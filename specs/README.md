# Specs

One folder per spec: `NNN-slug/{spec.md, acceptance.feature, mockup.html?, plan.md, tasks.yaml, workorder.json}` (plan sections
5.2 and 5.3). Spec numbers by milestone, the pipeline and what the gate says: `docs/runbooks/working-in-the-factory.md`.

- `spec.md` frontmatter: `factory/schemas/spec.schema.json`. Sections: Problem, Acceptance criteria (`- AC-001 WHEN … THE
SYSTEM SHALL …`), Out of scope, Notes for the planner.
- `acceptance.feature`: one or more Gherkin scenarios per AC, tagged `@AC-001`.
- `tasks.yaml`: `factory/schemas/tasks.schema.json`. `workorder.json` is generated by `npm run factory -- compile NNN`.
- `approvals.json` (this folder) records human agreement: written only by `npm run factory -- approve NNN --by <email>`.
